## What this repository contains

Original instructions, mapping tables and code written for coding agents, plus **text-only structural facts** about Apple's kits (component names, variant axis names and values, Figma node ids). It does **not** contain Apple Design Resources artwork: no exported images, SVGs, screenshots, Figma file data, fonts or SF Symbols.

## Apple Design Resources

Apple's UI kits are distributed under the *Apple Design Resources License Agreement* (shown on each kit's License page). In summary, as read by the authors (not legal advice):

- The resources are for creating **mock-ups of user interfaces for software that runs on Apple operating systems**.
- You may not extract, copy, modify, repackage, redistribute or embed the Template Content, or use it for non-Apple-OS software.
- The San Francisco font and SF Symbols are under separate licenses.

Read the license in your own copy of each kit before use. The skills in this repo direct agents to read the kits through the user's own Figma copy and to write original code. The `apple-ui-web` skill produces an approximation from public Human Interface Guidelines principles and does not reuse kit artwork; consider whether your web use fits Apple's terms.
